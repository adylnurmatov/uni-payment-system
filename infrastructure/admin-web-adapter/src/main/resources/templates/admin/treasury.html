Как пополнить казну

  1. Скопируйте адрес казны.
  2. Откройте кран Google Cloud Sepolia Faucet и войдите в Google-аккаунт.
  3. Выберите сеть Ethereum Sepolia, вставьте адрес и нажмите Receive.
  4. Через 15–30 секунд обновите страницу — баланс вырастет.

Кран нужен только казне: клиенты и мерчанты получают тестовый ETH отсюда (страницы «Клиенты» и «Мерчанты»). Монеты тестовые и ничего не стоят.
